# Authentication Project

Система аутентификации пользователей на основе клиент-серверной архитектуры, реализованная на языке Go.

## Описание

Проект представляет собой систему управления пользователями с поддержкой регистрации, авторизации и управления учетными записями. Система включает в себя серверную часть, обрабатывающую запросы клиентов, и клиентское приложение с консольным интерфейсом.

## Основные возможности

### Для обычных пользователей:
- **Регистрация** - создание новой учетной записи
- **Авторизация** - вход в систему
- **Смена пароля** - изменение текущего пароля
- **Удаление аккаунта** - удаление собственной учетной записи

### Для администратора:
- **Просмотр всех пользователей** - получение списка всех зарегистрированных пользователей
- **Удаление пользователей** - удаление учетных записей других пользователей

## Технологии

- **Язык программирования**: Go 1.24.5
- **Хеширование паролей**: bcrypt (golang.org/x/crypto)
- **Протокол связи**: TCP/IP
- **Формат данных**: JSON
- **Хранилище данных**: JSON файл (users.json)

## Установка и запуск

### Требования

- Go версии 1.24.5 или выше
- Установленный пакет `golang.org/x/crypto`

### Установка зависимостей

```bash
go mod download
```

### Запуск сервера

```bash
cd server
go run main.go server.go storage.go handler.go admin.go types.go
```

Или из корневой директории:

```bash
go run server/*.go
```

Сервер запустится на `localhost:8080`.

### Запуск клиента

В новом терминале:

```bash
cd client
go run main.go authentication.go clients_protocol.go utils.go
```

Или из корневой директории:

```bash
go run client/*.go
```

## Использование

### Первый запуск

При первом запуске сервера автоматически создается администраторская учетная запись:
- **Логин**: `admin`
- **Пароль**: по умолчанию установлен предварительно сгенерированный хеш

### Клиентское приложение

После запуска клиента вы увидите главное меню:

```
Меню:
1 - Зарегистрироваться
2 - Войти
0 - Выход
```

#### Регистрация нового пользователя

1. Выберите пункт `1` в главном меню
2. Введите логин (должен быть уникальным)
3. Введите пароль (минимум 6 символов)

#### Вход в систему

1. Выберите пункт `2` в главном меню
2. Введите логин и пароль

После успешного входа:
- **Обычный пользователь** получит доступ к панели пользователя
- **Администратор** получит доступ к панели администратора

#### Панель пользователя

```
Доступные функции:
1 - изменить пароль
2 - удалить пользователя
0 - выйти из аккаунта
```

#### Панель администратора

```
|ADMIN PANEL|
Меню:
1 - вывести всех пользователей
2 - удалить пользователя
0 - выйти из панели администратора
```

## Протокол связи

Система использует JSON-протокол для обмена сообщениями между клиентом и сервером. Все сообщения обернуты в структуру `Message`:

```go
type Message struct {
    Type string          `json:"type"`
    Data json.RawMessage `json:"data"`
}
```

### Типы сообщений

- `register` - регистрация нового пользователя
- `authorization` - авторизация пользователя
- `changePassword` - изменение пароля
- `deleteUser` - удаление пользователя
- `getAllUsers` - получение списка всех пользователей (только для администратора)

## Безопасность

- Пароли хранятся в виде bcrypt хешей, а не в открытом виде
- Используется стандартная стоимость bcrypt (DefaultCost = 10)
- Минимальная длина пароля: 6 символов
- Для удаления аккаунта требуется подтверждение паролем

## Хранение данных

Данные пользователей хранятся в файле `server/users.json` в формате JSON. Структура файла:

```json
{
    "login": {
        "Password": "bcrypt_hash"
    }
}
```
